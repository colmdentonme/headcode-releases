# Headcode releases

**Every service, on the record.**

Headcode is an automatic journey tracker and logbook for Train Sim World 7. This repository only hosts the Windows installers; installed copies of Headcode check here for updates.

## Install

1. Download `Headcode-Setup-x.y.z.exe` from the [latest release](https://github.com/colmdentonme/headcode-releases/releases/latest).
2. Run it. The installer isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": choose **More info → Run anyway**.
3. In Steam, add `-HTTPAPI` to Train Sim World 7's launch options, start the game once, and get into a cab.

Headcode updates itself: new versions download in the background and install when you close it, or when you click **Restart to update**.

`Headcode-Portable-x.y.z.exe` runs without installing but doesn't update itself.

Headcode is an unofficial fan project and is not affiliated with Dovetail Games.
